# FloraGest - Documentação

Esta é a documentação do **FloraGest**, um sistema para ajudar floriculturas de pequeno e médio porte a controlar o estoque de flores e insumos.

O projeto surgiu para resolver problemas como:

- Perdas de produtos por validade vencida;
- Falta de controle sobre o estoque;
- Dificuldade em usar planilhas e sistemas genéricos.

## Funcionalidades principais

- Cadastro de flores e insumos;
- Controle de validade com alertas;
- Controle de estoque mínimo e máximo;
- Relatórios e indicadores;
- Leitura de QR Code (em fases futuras);
- Sistema simples e fácil de usar.

## Tecnologias usadas

- Frontend: React
- Backend: FastAPI (Python)
- Banco de dados: MySQL

## Organização do projeto

- Metodologia ágil com sprints semanais;
- Divisão do time em duplas por área;
- Reuniões de acompanhamento e planejamento;
- Testes contínuos e revisão de código.
